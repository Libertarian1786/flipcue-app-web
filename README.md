# flipcue.app

The FlipCue website as served at https://flipcue.app. Generated by `tools/build_site.py` in the app repo - do not edit here.

Separate from `flipcue-site` on purpose: that repo serves the github.io URLs App Store Connect points at for 1.0, and giving it a custom domain would redirect those links to a domain that was not serving HTTPS yet.
